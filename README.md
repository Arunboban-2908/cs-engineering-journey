# 📚 Learning Method

For every topic, I follow:

```text
LEARN
  ↓
THINK
  ↓
CODE
  ↓
TEST
  ↓
REVIEW
  ↓
PUSH
  ↓
NEXT
```

I don't consider a topic complete just because I finished reading or watching it.

A topic is considered complete when I can **demonstrate my understanding by explaining it, implementing it, testing it, and solving problems with it.**

---

# 🧠 Learning Principles

### 1. Understand before memorizing

I focus on understanding why something works rather than memorizing code.

### 2. Write the code myself

Implementations are written by me in my development environment.

### 3. Use mistakes as part of learning

Errors, bugs, and failed attempts are part of the process.

### 4. Test everything

Code should be tested with normal cases, edge cases, and unexpected inputs where appropriate.

### 5. Understand complexity

For algorithms and important operations, I learn their:

* Time Complexity
* Space Complexity

### 6. Don't rush

The goal is genuine understanding, not simply finishing topics as quickly as possible.
